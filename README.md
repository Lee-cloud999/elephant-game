# 코순이 키우기

첫째 딸의 애착 코끼리 인형 코순이를 아기 코끼리로 키우는 웹 게임이에요.
먹이고, 씻기고, 놀아 주고, 재우면 쑥쑥 자라요. 모은 코인으로 꾸미기 아이템도 살 수 있어요.

## 하는 법

- 코순이를 콕 누르면 반응해요.
- **먹이**: 바나나, 수박, 땅콩, 물. 브로콜리, 당근, 양배추는 코순이가 싫어해요.
- **씻기 / 놀기 / 자기**: 상태 막대(배부름, 목마름, 깨끗함, 기분, 기운)를 채워 주세요.
- **쓰다듬기**: 버튼을 누른 뒤 코순이 머리 위에서 손가락을 문지르면 기분이 좋아져요.
- **산책**: 12초 동안 걸으면서 지나가는 나비와 꽃을 눌러 코인을 모아요.
- **병원**: 상태가 오랫동안 나쁘면 코순이가 아파요. 병원에서 청진기, 체온계, 약으로 치료해요.
- 놀다가 뜨는 하트를 눌러 코인을 모아 **꾸미기**에서 쓰세요.
- **꾸미기 → 몸 색깔**에서 코순이를 파랑(기본), 분홍, 민트, 노랑, 보라, 회색으로 바꿀 수 있어요. 무료이고 저장돼요.
- **꾸미기 → 뽑기**: 코인 10개로 랜덤 아이템을 뽑아요. 등급은 보통(60%) · 희귀(28%) · 레전더리(10%) · 시크릿(2%)이에요. 겹치면 등급에 따라 코인 4~10개를 돌려받아요. 레전더리와 시크릿은 뽑기에서만 나와요. (아이템이 아직 없는 등급은 건너뛰고 확률이 다시 계산돼요.)
- **아이템 25종**: 보통 7(리본, 꽃·새싹·하트·별·구름무지개·체리 핀), 희귀 8(안경, 목도리, 파티 모자, 날개·보라 리본·레이스 리본·눈꽃·달별 핀), 레전더리 5(왕관, 마법사 모자, 별무지개 날개 머리띠, 꿀잠 모자, 프릴 머리띠), 시크릿 5(천사 날개 후광, 박쥐 날개, 꽃 화관, 날개 티아라, 은하수 머리띠)예요. 보통·희귀는 코인으로 살 수도 있어요.
- **꾸미기 → 아이템 위치·크기 바꾸기**: 입은 아이템을 화면에서 끌어 옮기고 +/−로 크기를 바꾼 뒤 **저장**을 누르면 저장돼요.
- **레벨**: 먹이고 놀아 주면 경험치가 쌓여 Lv.1부터 Lv.50(만렙)까지 자라요. Lv.20까지는 몸집이 점점 커지고, 그 뒤로는 칭호가 바뀌어요(대장, 슈퍼, 전설의 코끼리).
- **새 코끼리**: 만렙이 되면 도감에 기록하고 새 코끼리를 처음부터 키울 수 있어요. 코인과 모은 아이템은 그대로예요.
- **도감**: 키우는 중인 코끼리와 졸업한 코끼리 목록(이름, 색깔, 입은 아이템, 키운 기간)이 저장돼요.
- **도감 → 화면에 부르기**: 만렙 코끼리는 화면에 두 마리까지 불러 같이 놀 수 있어요(눌러 보세요). 도감에서 **이어 키우기**를 누르면 그 코끼리가 주인공이 되고, 키우던 코끼리는 도감에서 기다려요. 능력치, 아이템, 색깔이 그대로 저장돼요.
- **학교**: 아기 코끼리(Lv.1~4) 때만 나타나는 버튼이에요. 아침(06~12시)에만 갈 수 있고 하루 한 번이에요. 글자와 숫자를 배우고 경험치와 코인을 받아요.
- 진행 상황은 그 기기의 브라우저에 저장돼요.

## 소리 설정

오른쪽 위 스피커 버튼을 누르면 소리 설정이 열려요.

- 배경음악과 효과음을 따로 켜고 끄고, 음량을 조절할 수 있어요.
- 배경음악 5곡 중에서 고를 수 있어요: 햇살 산책, 코끼리 왈츠, 달빛 자장가, 신나는 행진, 숲속 아침.
- 음악은 파일이 아니라 코드로 직접 연주해요. 곡을 고치려면 `index.html`의 `TRACKS` 부분을 수정하세요.
- 브라우저 규칙상 화면을 처음 한 번 누른 뒤부터 소리가 나요.

## 파일

- `index.html`: 게임 전체 (HTML, CSS, JavaScript가 한 파일)
- `assets/`: 코순이 표정 이미지 7장 (`idle` 기본, `sad` 시무룩, `sleep` 잠자는 중, `eat` 먹는 중, `angry` 화남, `joy` 활짝 웃음, `surprise` 놀람)

이미지를 바꾸려면 같은 이름의 파일로 교체하면 돼요. 크기는 640x520, 배경은 투명, 코순이는 가운데 아래쪽에 두면 꾸미기 아이템 위치가 맞아요.

## GitHub Pages로 열기

저장소 Settings → Pages → Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하세요.

- 📷 카메라: 지금 화면(코끼리, 꾸민 아이템, 배경 그대로)을 사진으로 찍어 앨범에 저장해요. 최대 20장.
- 🖼️ 앨범: 찍은 사진 보기와 지우기.
- 📞 전화: 바나나와 만렙(Lv.50) 코끼리에게 전화해요. 하루 3번까지 통화 보상(코인 2개).
- 💬 문자: 바나나와 만렙 코끼리가 하루에 한 번씩 선물 코인을 보내 줘요. 안 읽은 문자는 빨간 점으로 알려 줘요.
- 🕒 시계: 아날로그·디지털 시계와 지금 시간대 안내.
- 바나나 캐릭터 이미지: `assets/banana/` (7가지 표정)
